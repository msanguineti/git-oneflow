# Repository guidance

Read [ENGINEERING.md](ENGINEERING.md) for the project purpose, sources and working
policy, and [CONTRIBUTING.md](CONTRIBUTING.md) for setup and checks. Inspect the
current Git state and relevant code before changing anything. Use the applicable
Hypercliq Engineering methods and the governing organizational instructions.

Keep active coordination and review evidence in ignored `.dev/` when needed; if
it is absent, reconstruct the current state from durable documents, Git and code
without inventing decisions. Do not commit local coordination records.

Choose tests for meaningful behavior and credible regressions. Keep user-facing
documentation accurate when behavior changes, and maintain contributor guidance
when setup or checks change. Review consequential work with appropriate independent
expertise; report any unavailable evidence or review.
